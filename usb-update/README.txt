EARN TO FIRE - QUESTION SET USB
================================

Changes which questions the game asks. Works with no internet.

1. Plug this USB stick into the ARENA SERVER (the Windows box under the arena).
2. Open the stick in File Explorer.
3. RIGHT-CLICK the file you want and choose "Run as administrator":

     1-SWITCH-TO-KS2.bat   ages 7-11  (primary schools)  <- use this for STEMfest
     2-SWITCH-TO-KS3.bat   ages 12-14 (secondary schools)

4. Wait for "DONE". It takes about 15 seconds.
5. On the referee iPad, log in again. The arena restarts SAFE, so re-arm it when ready.

Scores and the leaderboard are kept. You can switch back and forth as often as you like.

If anything goes wrong, the script puts the old questions back by itself and nothing is
broken. Take a photo of the screen and send it to Ben.

What's on the stick
-------------------
  question-sets\ks2.js   the KS2 questions (72)
  question-sets\ks3.js   the KS3 questions (72)
  question-sets\check.js checks a question file before it goes live
  _install.bat           does the work (called by the two SWITCH files)
